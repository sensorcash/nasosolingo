# Свои картинки и иконки

Всё, что лежит в этой папке, сервер раздаёт по адресу `/static/img/...`

```
web/img/
├── icons/           24 иконки интерфейса + иконка приложения
│   ├── app-icon-180.png    иконка на домашнем экране (iPhone)
│   ├── app-icon-512.png    иконка большого размера
│   └── *.svg               иконки интерфейса
└── pump-types.jpg   пример картинки внутри урока
```

## Каталог иконок

Открой **http://localhost:8000/icons** — там все иконки разом, с названиями
файлов и на тех фонах, где они реально используются. Удобно понять,
что именно менять.

Набор (24 штуки):

| Группа | Иконки |
|---|---|
| Показатели | `streak`, `xp`, `life`, `life-empty`, `level`, `goal`, `accuracy`, `time` |
| Узлы карты | `done`, `current`, `locked` — белые, лежат на цветных кружках |
| Обратная связь | `ok`, `fail`, `warn` |
| Навигация | `close`, `back`, `arrow`, `menu` |
| Разделы | `review`, `lesson`, `user`, `export`, `logout`, `delete` |

Все нарисованы в едином стиле: сетка 24×24, линия толщиной 2, скруглённые концы.
Цвет запечён в файл. Весь набор весит 7,5 КБ.

**Перерисовать набор заново:** `python tools/make_icons.py` — там же меняются
цвета и формы, если хочется поправить сразу все.

## Как поменять иконку приложения

Замени файлы `icons/app-icon-180.png` и `icons/app-icon-512.png` своими
(квадратные PNG, 180×180 и 512×512). Больше ничего править не нужно.

На iPhone после замены удали иконку с домашнего экрана и добавь заново —
старая остаётся в кэше.

## Как поменять иконки интерфейса

Открой `web/index.html`, найди блок `const ICONS` в самом начале скрипта:

```js
const ICONS = {
  streak:  '🌊',   // поток
  xp:      '⚡',   // опыт
  life:    '💧',   // капля-жизнь
  done:    '✓',    // урок пройден
  current: '💧',   // текущий урок
  locked:  '🔒',   // урок закрыт
  ...
};
```

Замени эмодзи на имя своего файла:

```js
  xp: 'icons/icon-xp.png',
  life: 'icons/icon-life.png',
```

Короткое имя ищется в `web/img/`. Можно указать и полный путь
(`/static/img/...`) или ссылку на внешний адрес.

Менять можно по одной: часть иконок остаётся эмодзи, часть — картинками.

**Размер.** Иконки интерфейса подстраиваются под текст автоматически.
Удобный исходник — квадрат 64×64 или 128×128 с прозрачным фоном (PNG),
либо SVG.

## Как добавить картинку в вопрос урока

В `seed.py` у любого вопроса можно указать три поля:

```python
{
    "id": "q1",
    "type": "mc",
    "prompt": "Какой насос опускают прямо в скважину?",
    "image": "pump-types.jpg",
    "image_alt": "Описание для тех, кто не видит картинку",
    "image_caption": "Подпись под картинкой",
    ...
}
```

Положи файл в `web/img/`, укажи имя в `image`, запусти `python seed.py` —
и картинка появится в уроке. Работает для всех типов заданий.

**Рекомендации.** Ширина 800–1200 px, формат JPG для фотографий и PNG
для схем с текстом. Держи файлы до ~300 КБ: на мобильном интернете
большие картинки грузятся заметно долго.

## Как заменить маскота

Тритон нарисован кодом (SVG) в функции `mascot()` в `web/index.html`.
Чтобы поставить свои рисунки, замени её содержимое на картинки:

```js
function mascot(mood, cls){
  return `<img class="mascot ${cls||''}" src="/static/img/mascot-${mood}.png" alt="">`;
}
```

Тогда понадобятся четыре файла в `web/img/`:
`mascot-happy.png`, `mascot-neutral.png`, `mascot-worried.png`, `mascot-party.png`.

## После любых изменений

Обнови страницу через `Ctrl+Shift+R` — браузер кэширует картинки
и без этого покажет старые.
