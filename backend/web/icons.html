Иконки приложения

Все файлы лежат в web/img/icons/. Чтобы заменить иконку — положи свой файл с тем же именем, либо укажи другое имя в блоке const ICONS в начале web/index.html. Подходят SVG, PNG, JPG. После замены обнови страницу через Ctrl+Shift+R.
