# Часть 3. Приложение на телефоне

Теперь у сервера появился настоящий клиент. Он открывается в браузере на компьютере
и в Safari на твоём айфоне — без Mac, без Apple-аккаунта, без установки чего-либо.

Времени: 5 минут.

---

## Шаг 1. Обновить проект

1. Останови сервер (`Ctrl+C` в окне uvicorn).
2. Распакуй новый архив поверх папки проекта, с заменой файлов.

Появится новая папка `web` — это и есть приложение.

---

## Шаг 2. Запустить

```
docker compose up -d
.venv\Scripts\python -m uvicorn app.main:app --reload --host 0.0.0.0
```

Обрати внимание на `--host 0.0.0.0` — без него сервер отвечает только самому компьютеру,
и с телефона достучаться не выйдет.

---

## Шаг 3. Открыть на компьютере

```
http://localhost:8000/app
```

Логин и пароль уже подставлены (`admin` / `12345`) — просто нажми «Войти».

Дальше: карта-скважина с уроками → тапни светящийся кружок → пройди урок →
на финальном экране увидишь начисленный опыт. Всё это живые данные с твоего сервера.

---

## Шаг 4. Открыть на айфоне

Телефон должен быть в той же Wi-Fi сети, что и компьютер.

**Узнай IP компьютера.** В PowerShell:

```
ipconfig
```

Найди строку `IPv4-адрес` — обычно вида `192.168.1.42`.

**На айфоне открой в Safari:**

```
http://192.168.1.42:8000/app
```

(подставь свой адрес)

**Добавь на домашний экран:** кнопка «Поделиться» → «На экран "Домой"». После этого
приложение запускается с иконки и открывается на весь экран, без адресной строки —
выглядит почти как настоящее.

---

## Что уже работает

- вход с сохранением сессии (в следующий раз откроется сразу на карте);
- карта-скважина: пройденные уроки зелёные, текущий подсвечен, следующие закрыты;
- все четыре типа заданий: выбор варианта, поиск ошибки на схеме, ползунок глубины, сопоставление;
- разбор каждой ошибки с объяснением;
- начисление опыта, списание капель, счётчик потока;
- маскот Тритон с разными настроениями;
- защита от двойного начисления, если связь моргнула;
- автоматическое обновление сессии, когда токен протухает.

---

## Если что-то не так

| Что видишь | Решение |
|---|---|
| С телефона не открывается | Проверь `--host 0.0.0.0` и что телефон в той же сети |
| Не открывается, хотя всё верно | Брандмауэр Windows блокирует порт — разреши доступ для Python в частной сети |
| «Уроков нет» | Запусти `.venv\Scripts\python seed.py` |
| Не пускает admin/12345 | Запусти `.venv\Scripts\python seed_dev.py` |
| Пустая белая страница | Папка `web` не распаковалась — проверь, что она есть рядом с `app` |
| Ошибка 404 на `/app` | Сервер запущен из другой папки; перезапусти из корня проекта |

## Про этот шаг честно

Это веб-приложение, а не нативное. Отличия, которые заметны:

- **нет пуш-уведомлений** — напоминать о занятиях пока нечем;
- нужен запущенный сервер на компьютере (пока не выложим его в интернет);
- нет офлайн-режима — он появится, когда добавим кэш уроков.

Всё это решается на следующих шагах. Но интерфейс, ощущение от игры и вся работа
с сервером — настоящие, и их можно показывать людям уже сейчас.
